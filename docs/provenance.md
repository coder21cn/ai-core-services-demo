# Project provenance

This is a personal educational reference implementation, developed with AI assistance. Coding agents
contributed implementation, tests, documentation and iterative reviews. It is not AVEVA software and
does not represent any company's internal architecture or demonstrate production operating experience.

The public repository begins with a cleaned snapshot of an existing private development repository.
Its earlier commit/PR history and personal planning notes are not included. Historical commit hashes,
PR numbers and verification results retained in these documents refer to that private development
history; they are not commits or pull requests in the public repository. Commands and tests remain
available for readers to reproduce the current behavior. Public CI records start with the snapshot.

M1 and M2 are implemented within the documented reference scope. M3 instrumentation, architecture and
seven decision records are implemented. The technical assessment and follow-up reviews were performed
by the implementing agent; **independent second-reviewer sign-off remains pending**. Passing tests and
repeated reviews do not prove the absence of bugs. Personal interview preparation is separate.

No production throughput, real model quality, cost accounting, enterprise identity or deployment
readiness is claimed. See [the assessment](architecture-review.md) for open risks and
[verification](verification.md) for observed results, including failures encountered during development.
